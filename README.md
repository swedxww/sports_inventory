# Учёт спортивного инвентаря в зале

## 1. Описание проекта

Проект «Учёт спортивного инвентаря в зале» предназначен для организации хранения информации о спортивном оборудовании и контроля его наличия.

Система разрабатывается на языке программирования Python. Проект создаётся в рамках лабораторных работ и предназначен для изучения разработки программного обеспечения, организации файлов проекта, работы с Git и размещения кода на GitHub.

## 2. Предметная область

Предметная область проекта — учёт спортивного инвентаря, используемого в спортивном зале.

В спортивном зале может находиться различное оборудование: гантели, гири, мячи, скакалки, коврики и другие спортивные принадлежности. Для эффективной организации работы необходимо хранить сведения об инвентаре, знать его количество и иметь возможность быстро получать информацию о наличии необходимого оборудования.

Автоматизация учёта позволяет упростить работу с информацией, уменьшить вероятность ошибок при ведении записей и облегчить контроль за спортивным инвентарём.

Основными объектами предметной области являются:
- **Спортивный инвентарь** — оборудование и принадлежности, используемые в зале.
- **Запись об инвентаре** — информация о конкретном виде оборудования.
- **Количество** — число единиц определённого вида инвентаря.
- **Сотрудник зала** — пользователь, который работает с информацией об инвентаре.

## 3. Возможности проекта

Планируемые возможности системы:
- просмотр списка спортивного инвентаря;
- добавление новых записей об инвентаре;
- изменение информации о существующем инвентаре;
- удаление записей;
- просмотр количества единиц оборудования;
- контроль наличия необходимого инвентаря.

**Текущая реализация:** на данном этапе программа выполняет проверочный вывод `maga`. Перечисленные функции учёта являются планируемыми и будут реализованы в ходе дальнейшей разработки.

## 4. Архитектура проекта

Проект предполагает простую модульную архитектуру. Программа может быть разделена на несколько логических компонентов:

1. **Пользовательский интерфейс** — обеспечивает взаимодействие сотрудника с программой.
2. **Логика учёта** — отвечает за добавление, просмотр, изменение и удаление записей.
3. **Работа с данными** — обеспечивает хранение и получение информации о спортивном инвентаре.

В текущей версии реализован только основной файл запуска программы. Остальные компоненты описывают предполагаемую архитектуру будущей системы.

Главный файл проекта. Содержит точку входа в программу и запускает её выполнение.
